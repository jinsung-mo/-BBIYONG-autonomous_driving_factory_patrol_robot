# Orin 개발 대시보드 — FE 참조본

로봇(Jetson Orin Nano) 위에서 **실제로 돌아가고 있는** 관제 화면이다.
로봇 상태·카메라·2D 지도·라이다 스캔·수동조종이 한 페이지에 들어 있고, 의존성이 0이다(npm·CDN 없음).

`S15P11E101-431`(FE 관제 단일 화면)에서 **같은 것을 React 로 다시 만든다.**
이미 실물에서 틀려 보고 고친 판단들이 여기 들어 있으니, 그걸 가져가라고 둔 사본이다.

> ⚠️ **이건 사본이다. 고치지 마라.**
> 실행되는 정본은 **`BE_robot/orin_dashboard/`** 다.
> 여기 파일을 고쳐도 로봇에는 아무 영향이 없고, 정본과 어긋나기만 한다.

> 🔴 **이 사본은 `main` 은 물론 `be_robot/dev` 보다도 앞서 있다 (2026-07-28 기준).**
> `nav_protocol.py` 의 `robot_view()`(heading-up 변환)와 `index.html` 의 카메라 자기페이싱 루프는
> **아직 `be_robot/dev` 에 머지되지 않은** `feat/S15P11E101-372-dashboard-heading-up-view` 의 내용이다.
> 즉 **§3·§5 에서 설명하는 기능 일부는 `BE_robot/orin_dashboard/` 를 열면 아직 안 보인다.**
> 참조 목적에는 최신본이 맞다고 판단해 이쪽을 담았다. 그 브랜치가 머지되면 이 경고는 지워도 된다.

## 1. 원본과 무엇이 다른가 (내가 손댄 것)

참조용으로 만들면서 **덜어낸 것만 있다. 기능을 새로 넣거나 로직을 바꾸지 않았다.**

| 뺀 것 | 규모 | 왜 |

| **3D 설계 갤러리 페이지**(`설계` 탭 전체 — CSS·HTML·JS·라이트박스·`probeDesign()` 계열) | **−205줄** | 우리 팀 3D 출력물 뷰어다. **FE 와 아무 상관이 없다.** 8초마다 `design/manifest.json` 을 찔러대는 폴링도 같이 사라진다 |

**결과: 2,254줄 → 2,047줄 (122KB → 111KB).**
잘라낸 뒤 검증했다 — 잔여 참조 0건, `node --check` 통과, HTML 태그 균형(`section` 5/5 · `div` 230/230).

> 🔴 **잘라내다 죽을 뻔한 곳이 하나 있었다.** 라이트박스(`#lb`)를 지우면
> `Escape` 키 핸들러의 `$('lb').classList.remove('on')` 이 **null 참조로 죽고,
> 그 줄이 비상정지보다 앞에 있어서 `Escape` 비상정지가 통째로 안 먹는다.**
> 이 참조본에서는 그 줄만 같이 제거해 비상정지를 살려 뒀다.
> **여러분이 기능을 덜어낼 때도 같은 일이 난다** — 전역 단축키에 딸린 DOM 참조를 먼저 확인하라.

**안 담은 파일** — `wsproto.py`(WebSocket RFC 구현), `nav_bridge.py`(rclpy 브리지), `restart.sh`, `tests/`,

전부 로봇 런타임 전용이라 FE 가 볼 값어치가 없다.
→ **그래서 이 사본은 실행되지 않는다.** 실행이 필요하면 `BE_robot/orin_dashboard/` 를 봐라.

## 3. 기능 지도

`static/index.html` 기준. **줄 번호보다 함수 이름이 안전하다**(파일이 바뀌면 번호는 밀린다).

### 데이터 수송 — 전부 `fetch` 폴링이다
**WebSocket 도 SSE 도 MJPEG 도 안 쓴다.** 경로는 **전부 상대경로**(`api/state`, 앞에 `/` 없음).

| 엔드포인트 | 호출부 | 주기 |
|---|---|---|
| `api/state` | `pollState()` | 2초 |
| `api/nav/live` | `pollNav()` :1514 | 0.5초(주행 화면) / 4초 |
| `api/nav/map` | `loadMap()` :1491 | `map_sequence` 가 바뀔 때만 |
| `api/cam` | `camLoop()` :1634 | **자기 페이싱 ~10Hz** |
| `api/drive` GET | `pollDrive()` :1867 | 0.5초(제어 화면) / 10초 |
| `api/drive` POST | `drvSend()` :1845 | **무장 중 10Hz 데드맨** :2017 |

마스터 스케줄러 `tick()` :2022 + `setInterval(tick, 500)` :2032. 백그라운드 탭이면 전부 멈춘다.

> 💡 **상대경로는 의도적이다.** 이 페이지는 `http://orin:8090/` 에서도, nginx 하위경로
> `https://…/robot/` 에서도 **수정 없이** 돈다. 절대경로 `/api/...` 로 바꾸면 하위경로 배포가 깨진다.
> 서버는 SSE(`GET /api/stream`)도 제공하지만 **이 페이지는 안 쓴다** — 필요하면 쓸 수 있다.

### 로봇 상태
- `renderState()` :1293 — `/api/state` 의 유일한 소비자. 상태 레일 → 사이드바 → 타일 → 게이지 → 코어바 → 전력 → 온도 → ROS 토픽 → 장치 순.
- 임계 판정 **함수**는 `lvl(v, warn, crit)` :867 하나다. CPU 70/88, Tj 65/80, RAM 75/90, 디스크 80/92.
  ⚠️ **그런데 숫자는 공유되지 않는다** — 같은 `65,80` 이 호출부마다 반복되고, CSS 눈금(`--w:65%;--c:80%`)에
  **네 번째로** 또 박혀 있다. 이 파일에서 제일 나쁜 중복이다. **여러분은 상수로 빼서 시작하라.**
- 라디얼 게이지 `makeGauge()` :1011 — **순수 SVG**, 270° 스윕, 레드라인 호. 라이브러리 없다.
- 스파크라인 `spark()` :959 — 서버는 히스토리를 안 준다. **클라이언트가 150샘플 링버퍼**(`HCAP` :943, 2초 간격 ≒ 5분)로 들고 있다.
- **배터리는 값이 안 온다.** INA226 미배선이라 `connected:false` 만 온다. 잔량·전류·주행가능시간은 **어디에도 없다.**

### 카메라 — base64 JPEG 를 JSON 에 담아 폴링
**MJPEG 도 WebRTC 도 아니다.** `api/cam` 응답의 `jpeg` 필드(base64)를
`data:image/jpeg;base64,…` 로 만들어 `<img>` 3개(개요·카메라·제어 화면)에 물린다.
- `pollCam()` :1604, 재진입 가드 `camBusy` :1602
- `renderCam()` :1655 — 서버가 준 `out_w/out_h` 로 CSS 변수에 **종횡비를 먼저 박는다.** 이미지 로드 전에 박스가 튀지 않게.
- `drawCamOverlays()` :1763 — 탐지 박스는 `<img>` 위에 겹친 **별도 `<canvas>`** 에 그린다.

### 2D 지도 — 캔버스 + RLE + 패치
- **와이어 포맷**: `decodeMapSnapshot()` :1467. `cells` 는 **평평한 RLE 쌍 배열** `[값, 개수, 값, 개수, …]`.
  디코드 결과는 **셀당 1글자짜리 문자열 하나**(`.` 미지 / ` ` 자유 / `#` 점유) — 규격은 `nav_protocol.py`.
- **증분 패치**: `applyMapPatch()` :1480. `changes` 는 **평평한 3배수 배열** `[시작, 개수, 값, …]`.
  `seq === base_sequence` 일 때만 적용하고, 아니면 **전체 스냅샷을 다시 받는다** :1491.
- **협상**: `loadMap()` 이 `?since=<seq>` 를 보내고 **HTTP 304** 를 존중한다 :1497. 동시요청 중복은 `mapRequest` :1463 으로 막는다.
- **렌더**: `MapView()` :1077 — 팩토리로 **3번 인스턴스화**(주 지도·미니·제어용).
  - `bake()` :1106 — 격자 전체를 **셀당 1px 오프스크린 캔버스**에 `ImageData` 로 굽고 캐시한다. `seq` 가 바뀔 때만 다시 굽는다. **이게 성능의 핵심이다.**
  - `imageSmoothingEnabled = false` :1156 — 확대해도 셀이 뭉개지지 않게.
- 팬·줌은 주 지도에만. Pointer Events + `setPointerCapture` :1225, 휠 줌은 커서 기준.

### 라이다 스캔
`MapView` 안 :1189 근처. 각도는 `pose.yaw + angle_min + i*angle_inc`, 점은 `x + r·cos(a), y + r·sin(a)`.
2×2px `fillRect`. **`range === 0` 은 "거리 0"이 아니라 "무효"다** — 걸러야 한다.

### 자세·궤적·heading-up 변환
- 신선도 게이트 :1139–1140 `poseFresh = pose && pose.frame === 'map' && pose.stale !== true`
- **월드→화면** `point(mx,my)` :1143 — 로봇을 화면 중앙에 고정하고 **진행 방향을 항상 화면 위**로 둔다.
- 구운 이미지 쪽은 ctx 변환 체인 :1160 — `translate(중앙)` → `rotate(yaw − π/2)` → `scale(s, −s)` → …
- 궤적 `NAV.trail` :1172 — 3cm 중복제거, 4000점 상한.
- 자세가 낡으면 **마지막 신선한 자세에 화면을 얼리고** 캔버스에 경고 배너를 직접 그린다.

### 수동조종 — 유일한 쓰기 경로
- `drvVec()` :1832 → `drvSend()` :1845 (POST) → `pollDrive()` :1867 → `renderDrive()` :1893
- 무장 중 **10Hz 로 계속 POST** :2017. 아무 키도 안 눌렀으면 `v=0,w=0` 을 보낸다.
- 키보드 :1988 은 **`e.key` 가 아니라 `e.code`**. `Escape` 는 어느 화면에서든 비상정지 :1992.
- 포커스를 잃으면 자동 무장해제(페이지 이동·`blur`·`visibilitychange`·HTTP 503).

## 4. API 계약

`server.py` 가 정본. **FE 는 이 서버에 직접 붙지 않는다**(Spring 경유) — 필요한 건 **데이터 모양**이다.

| 메서드·경로 | 주는 것 |
|---|---|
| `GET /api/state` | 시스템 스냅샷. `system`·`thermal`·`disk`·`uptime_sec`·`ros{topics,scan_hz}`·`motor`·`battery`·`errors` |
| `GET /api/nav/live` | `{t, pose{frame,x,y,yaw,stamp,age,stale}, scan{angle_min,angle_inc,ranges[]}, view{map_to_view[6],stale}, map_sequence}` |
| `GET /api/nav/map?since=<seq>` | `sequence` 가 같으면 **304**. 다르면 스냅샷(`cells` RLE) 또는 패치(`changes` 3배수) |
| `GET /api/cam` | `{jpeg(base64), out_w, out_h, src_w, src_h, det[], img_ok, …}` |
| `GET /api/drive` | `{armed, v, w, reason, v_max, w_max, stop_m, patrol_running}` |
| `POST /api/drive` | `{armed, v, w}` 를 받고 `{ok, accepted:{…}}` 를 돌려준다 |

**공통 헤더 `X-Nav-Age`** — 이 응답 데이터가 몇 초나 묵었는지 **서버가 계산해서** 준다. (§5-1)

**HTTP 503 = "그 노드가 안 떠 있다"** — 에러가 아니라 **일급 상태다.**
`/api/drive` 가 503 이면 조종 노드가 죽은 것이니 **UI 를 강제 무장해제해야 한다.**

## 5. 함정 — 실물에서 틀려 보고 고친 것들

### 5-1. 🔴 신선도를 브라우저 시계로 계산하지 마라
`Date.now() - payload.t` 로 재면 **로봇과 PC 의 시계 차이가 그대로 섞인다.** 실제로 **−0.5초**(음수 나이)가 나왔다.
→ 서버가 계산한 **`X-Nav-Age` 응답 헤더**를 읽어라. 신선도 판정은 **데이터를 만든 쪽이 한다.**

### 5-2. 🔴 자세가 낡으면 화면을 얼리고, 말해라
로봇 중심 뷰는 **신선하고 `map` 프레임인 자세**가 있어야만 성립한다. 없을 때 그냥 그리면
지도가 튀거나 odom 좌표를 map 이미지에 얹어 조용히 틀린 그림이 된다.
→ **마지막 신선한 자세에 얼리고**, "TF 없음"과 "TF 지연"을 **다른 문구로** 알리고, **스캔 오버레이는 숨긴다.**

### 5-3. 🔴 영상 루프는 `setInterval` 로 돌리지 마라
AWS 터널 왕복이 **82.6ms** 로 실측됐다. 100ms `setInterval` 이면 왕복보다 빨라지는 순간
**요청이 겹쳐 쌓이고 프레임 순서가 뒤섞인다.**
→ **응답을 받은 뒤에 다음 요청을 낸다**(`camLoop()` :1634). 회선이 느려지면 저절로 느려진다.
실측 상한: keep-alive 단일 연결 **12.1 req/s**.

### 5-4. 좌표계 — 두 번 뒤집힌다
- **ROS 점유격자는 아래에서 위로, 캔버스는 위에서 아래로 쌓인다.** 행 뒤집기 :1117 `row = h-1-…`
- ctx 변환에도 뒤집기가 또 있다 :1160. **둘이 상쇄돼야 맞다.** 하나만 맞추면 **위아래가 뒤집힌 채로도 그럴듯해 보인다** — 이게 제일 잡기 어렵다.
- heading-up 은 단순 `rotate(-yaw)` 가 **아니다**. `yaw − π/2` 다.
- yaw 는 데이터에선 **라디안**, 표시할 때만 도(°).
- 스캔은 원래 `laser` 프레임인데 **`base_link` 에 그린다** — 6cm 오프셋이 보통 배율에서 1px 미만이라 의도적으로 무시했다.

### 5-5. `img_ok === false` 는 "깨끗함"이 아니라 **"모름"** 이다
바닥 판정값을 null 로 만들고 UI 에 **"모름"** 을 경고색으로 띄운다.
**낡았지만 안심되는 숫자를 그대로 보여주면 안 된다.** 이건 안전 요구사항이다.

### 5-6. 캔버스는 `display:none` 안에서 크기가 0이다
탭 전환 UI 의 고전적 함정. 모든 리사이즈 경로가 `width < 2` 면 그냥 빠져나오고,
화면을 켠 뒤 `requestAnimationFrame` 안에서 **다시 잰다** :1049.
DPR 은 `Math.min(2, devicePixelRatio)` 로 **2에서 자른다** :963 (Orin 성능).

### 5-7. 지도는 다시 굽지 마라
`seq` 가 바뀔 때만 `bake()`. 1000×1000 격자를 2Hz 로 매번 다시 그리면 **Orin 이 녹는다.**

### 5-8. 텔레옵 — GET 과 POST 의 응답 모양이 다르다
GET 은 `reason`·`v_max`·`stop_m`·`patrol_running` 을 주고, POST 는 `{ok,armed,v,w,ts}` 만 준다.
**POST 응답으로 상태를 덮어쓰면 `reason` 이 사라진다** — 실제로 그 버그가 났다. 따로 저장하라.
그리고 **요청한 v/w 가 아니라 로봇이 실제로 낸 v/w 를 표시**하고, 다를 때는 차이를 드러내라.
라이다 가드가 전진만 0으로 만들고 회전은 살려두는데, 이걸 숨기면 **로봇이 고장 난 것처럼 보인다.**

### 5-9. 키보드는 `e.key` 가 아니라 `e.code`
**한글 IME 에서 `W` 가 `ㅈ` 으로 들어온다.** `KeyW` 는 안 변한다.

### 5-10. 데드맨은 "안 보내기"가 아니라 "0을 보내기"
무장 중에는 아무 키도 안 눌려도 **10Hz 로 `v=0,w=0` 을 계속 보낸다.**
안 보내면 서버가 "데드맨 타임아웃"으로 판정해 운전자에게 뜨는 `reason` 문구가 달라진다.
타임아웃은 3중이다 — 서버 0.4초 · teleop 0.5초 · 펌웨어 1초.

## 6. 🔴 보안 — 그대로 베끼면 따라오는 것

이건 **개발용 도구**라 아래를 의도적으로 미뤄 뒀다. **제품 화면에 그대로 옮기지 마라.**

| | 문제 | FE 에서 해야 할 것 |
|---|---|---|
| **XSS** | 서버가 준 문자열이 **이스케이프 없이 `innerHTML`** 로 들어간다 — ROS 토픽 이름, 온도 센서 키, 서버 `error`/`hint` 문구, **탐지 라벨(`d.name`)** | React 는 기본이 이스케이프다. **`dangerouslySetInnerHTML` 만 안 쓰면 그냥 해결된다** |
| **인증** | 페이지에 **인증이 아예 없다.** 토큰도 `Authorization` 헤더도 없고 nginx Basic Auth 에 전부 위임 | 팀 인증(STOMP 토큰)을 태워야 한다 |
| **CSRF / 권한** | `POST /api/drive`(**로봇을 물리적으로 움직이는 유일한 경로**)에 **CSRF 토큰도 사용자 식별도 없다.** 비밀번호를 아는 사람은 전부 조종할 수 있고 **누가 조종했는지 안 남는다** | 조종 권한과 **감사 로그**가 필요하다 |
| **CORS** | `server.py` 가 `Access-Control-Allow-Origin: *` 를 준다(개발 편의) | 운영에서 쓰지 마라 |

## 7. 안 가져온 판단 — 참고만

- **`server.py` 는 표준 라이브러리만 쓴다.** 로봇에 pip 의존성을 안 늘리려는 것. ROS·OpenCV 가 필요한 부분은 별도 프로세스가 **JSON 파일로 떨구고**, 서버는 그 파일만 읽는다(원자적 교체라 반쯤 쓴 파일을 안 읽는다).
- **정적 서빙이 SPA 폴백이다** — 없는 경로에도 `index.html` 을 **200** 으로 돌려준다.
  그래서 **`res.ok` 가 "파일이 있다"를 뜻하지 않는다.** 존재 확인이 필요하면 본문 마커를 봐야 한다(`index.html` 2번째 줄 주석이 그 용도였다).
