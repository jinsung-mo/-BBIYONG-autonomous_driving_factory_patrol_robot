# 시뮬레이션 지도 페이지 설계 기록 (MapPage)

작성 시점: 2026-08-05
관련 티켓: S15P11E101-707

## 1. 개요
관제 화면을 지도와 카메라 두 화면으로 나눈 첫 번째 화면(`MapPage`)입니다. 지도는 구역 전체를 넓게 보아야 하므로, 우측 메인 캔버스에 거대하게 배치하고, 좌측에는 로봇 상태와 이벤트 로그를 곁눈으로 확인할 수 있게 구성했습니다.

## 2. 화면 구조 (`nav-stage`)
Navexa 디자인 스킨(`.sim-skin`)과 2분할 스테이지 레이아웃(`.nav-stage`)을 기반으로 구성됩니다.

```
┌────────────────────────────────────────────────────────────────┐
│ 상단 바 (Nav)                                                   │
├────────────────────────────────────────────────────────────────┤
│ [nav-hero] 타이틀 (순찰 구역 ORINCA FLEET) + KPI 요약 지표      │
├──────────────┬─────────────────────────────────────────────────┤
│ [nav-side]   │ [nav-canvas]                                    │
│ 순찰 로봇 상태│ 2D SLAM 매핑 캔버스                             │
│ (StatusPanel)│ (MapPanel)                                      │
│ - 배터리, 통신│ - 범례 (Map Legend)                             │
│ - 이벤트 로그 │ - 제어 도구 (줌, 오버레이 토글)                 │
└──────────────┴─────────────────────────────────────────────────┘
```

## 3. 주요 디자인 톤 (Navexa UI)
- **nav-side (좌측)**: `var(--nx-side-panel)` 변수를 사용해 어두운 유리 질감과 깊은 그림자(`var(--nx-sh-lg)`)를 적용. 캔버스 위에 한 단 띄워져 있는 인상을 줍니다.
- **nav-canvas (우측)**: `var(--nx-elev)`를 적용해 패널들 중 가장 넓은 면적을 시원하게 차지하며 얇은 그림자를 가집니다.
- **카드 내부 여백 제거**: `.nav-page .panel` 특성을 이용하여, 지도 캔버스가 카드 안에 갇히는 답답함을 없애고 배경 자체에 녹아들게 합니다.

## 4. 제어 및 인터랙션
- 지도의 뷰포트 이동과 확대/축소는 시뮬레이션 캔버스(`Simulation.ts`)에서 처리되며, UI에서는 우측 버튼(`map-controls`)을 통해 정해진 스텝으로 조작합니다.
- 전체 화면(`view-fullscreen`) 진입 시, 좌측의 `nav-side`와 상단의 `nav-hero`가 사라지고 맵이 화면 전체를 덮도록 설계되었습니다.
