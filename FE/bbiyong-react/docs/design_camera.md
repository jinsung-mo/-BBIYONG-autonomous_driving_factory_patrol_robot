# 시뮬레이션 카메라 페이지 설계 기록 (CameraPage)

작성 시점: 2026-08-05
관련 티켓: S15P11E101-707

## 1. 개요
관제 화면의 두 번째 축인 카메라 화면(`CameraPage`)입니다. 로봇의 시야(YOLO 비전)를 메인으로 확인하며, 눈으로 보고 직접 주행을 제어할 수 있도록 좌측에 수동 조작(Manual Control) 패널이 함께 위치합니다.

## 2. 화면 구조 (`cam-stage`)
지도와 동일하게 `.nav-page` 및 Navexa 프레임워크를 공유하되, 세부 분할은 카메라 조작에 최적화된 `.cam-stage`를 사용합니다.

```
┌────────────────────────────────────────────────────────────────┐
│ 상단 바 (Nav)                                                   │
├────────────────────────────────────────────────────────────────┤
│ [nav-hero] 타이틀 (전면 카메라 비전) + KPI 요약 지표            │
├──────────────┬─────────────────────────────────────────────────┤
│ [cam-side]   │ [cam-main]                                      │
│ 수동 조작 패널│ 메인 영상 캔버스 (FRONT + YOLOv11n)             │
│ (ControlPanel)│ - REC 상태, HUD (속도, 각도)                    │
│ - 주행 D-Pad │ - 맵 PiP (우하단 작은 지도 창)                  │
│ - 카메라 틸트 │ - 확대/축소 및 뷰포트 도구                      │
│ - 이벤트 로그 │                                                 │
└──────────────┴─────────────────────────────────────────────────┘
```

## 3. 주요 디자인 톤 (Navexa UI)
- **cam-side (좌측 조작부)**: 지도 화면의 `nav-side`와 동일한 짙은 `var(--nx-side-panel)` 재질을 적용하여, 물리적인 조작계가 화면 위에 떠 있는 듯한 입체감을 부여합니다.
- **cam-main (우측 영상부)**: `var(--nx-elev)` 밝은 톤의 캔버스를 통해 영상 자체에 집중할 수 있게 합니다.
- **HUD 및 상태 표기**: 속도와 배터리 등 무의미한 중복 지표는 제거하고, 녹화(REC) 표시와 렌즈 방향 등 필수 HUD 요소만 캔버스 오버레이로 띄웁니다.
- **PiP (Picture in Picture)**: 로봇이 향하는 방향을 놓치지 않도록, 메인 영상 우측 하단에 `.pip` 클래스의 작은 2D 지도 미니맵이 고정됩니다.

## 4. 제어 및 인터랙션
- **더블클릭 확대**: 메인 영상 패널을 더블클릭하면 영상을 화면 가득 채우는 전체화면(Full-canvas) 모드로 부드럽게 전환됩니다.
- 수동 조작이 시각적 판단과 직결되므로 조작부와 카메라 뷰포트는 절대로 상하로 겹치지 않게 배치했습니다.
